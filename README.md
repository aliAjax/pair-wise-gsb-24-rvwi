# hxwl-10 考古探方记录

遗址探方发掘班组交接与遗迹保护闭环档案

## 技术栈

React + Vite + TypeScript + CSS（不增加额外依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 功能闭环

- **每日进尺上报**：填写探方、地层、起始深度、进尺与现场负责人；同一探方进尺区间不得重叠，跨层必须补记层位
- **遗迹保护停挖**：发现遗迹单位（灰坑/墓葬/房址/沟状遗迹）后，所在及受影响探方转入保护停挖
- **保护措施与复挖**：未登记保护措施不能复挖；更换班组复挖时必须交接未完坐标与出土物暂存点，原班组的进尺与发现记录保持绑定
- **地层验收与更正**：验收过的地层只读，更正时另立带原因记录，历史数值沿更正链继续可查；未验收地层可直接修订
- **冲突定位**：任何校验冲突都显示探方、地层、深度、班组与原值
- **刷新一致**：档案通过 localStorage 持久化，刷新后探方、班组、停挖、交接与更正链保持一致；可一键恢复示例档案

## 分层结构

```
src/
  domain/   领域数据：types 类型、selectors 纯派生、seed 初始档案
  rules/   校验规则：validators 全部业务约束（与页面、存储解耦）
  state/   状态：reducer 纯变更 + store（useSyncExternalStore + localStorage）
  ui/      页面组件
```
