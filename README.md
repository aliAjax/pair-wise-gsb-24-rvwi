# hxwl-10 考古探方记录

遗址探方发掘：班组每日进尺上报、遗迹保护停挖复挖、班组交接与地层验收更正闭环档案。

## 技术栈

React + Vite + TypeScript + CSS（未新增任何依赖；React 类型以 `src/shims/react.d.ts` 本地最小垫片提供）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 业务闭环与规则

1. **每日进尺上报**：填写探方、地层、起始深度、进尺、现场负责人（及上报班组）。
   - 进尺区间按半开区间 `[起始, 起始+进尺)` 判定，同探方内**不得重叠**（首尾相接允许）；
   - 进尺跨越多个地层时**必须补记所跨层位**；
   - 探方处于保护停挖时禁止上报。
2. **遗迹保护停挖 / 复挖**：发现遗迹单位后受影响探方立即转入**保护停挖**；
   **未登记保护措施不能复挖**（页面与领域规则双重拦截）。
3. **班组交接**：复挖更换班组时，必须交接**未完坐标**与**出土物暂存点**（必填，无则填「无」），
   支持连续换班的交接链追溯；交接只更换当班班组，**原班组的进尺与发现记录永久绑定**。
4. **验收只读 / 更正留痕**：验收过的地层只读；确需更正时另立带**原因**的更正记录，
   **历史原值继续可查**（台账与地层更正链均展示 `原值 → 新值`）。
5. **刷新一致**：全部状态写入 `localStorage`，刷新后探方、班组、停挖、交接与更正链保持一致；
   存储损坏时安全回退演示数据。
6. **冲突展示**：任何校验失败均返回探方、地层、深度、班组与原值/冲突记录，页面逐条展示。

## 分层结构

```
src/domain/            领域数据与规则（纯 TypeScript，不依赖 React）
  types.ts             领域模型（探方、地层、进尺、遗迹、交接、更正、冲突 Issue）
  seed.ts              演示初始档案
  rules.ts             全部校验规则与状态变更（进尺/停挖/保护/交接/复挖/验收/更正）+ 链路自检
  storage.ts           localStorage 持久化（刷新一致、损坏回退）
src/components/        页面（只做展示与交互，规则全部调用 domain）
  Forms.tsx            四个作业页签
  TrenchBoard.tsx      探方—地层—进尺—遗迹—交接看板
  Ledger.tsx           台账与链路一致性自检
  widgets.tsx          冲突提示等通用组件
src/shims/react.d.ts   不新增依赖前提下的最小 React 类型垫片
scripts/               规则冒烟测试与页面 SSR 冒烟测试（esbuild 打包到 node 运行）
```
